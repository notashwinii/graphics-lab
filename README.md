# Graphics Lab

This repository contains graphics lab assignments and a miniproject for the Graphics course at Kathmandu University.

Each lab folder contains small programs and exercises used in the course to demonstrate core computer graphics algorithms and transformations.

## How to run

1. Use a Python 3.8+ environment.
2. For each lab or the miniproject, install dependencies found in the corresponding `requirements.txt` (if present). For example:

```bash
# from repository root
python -m venv .venv
source .venv/bin/activate
pip install -r lab_2/requirements.txt   # or lab_1/requirements.txt or miniproject/ecg/requirements.txt
```

3. Run the example script from the desired folder. Example:

```bash
python lab_2/circle.py
# or
python miniproject/ecg/main.py
```
